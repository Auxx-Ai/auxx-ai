# Sounds

Static audio assets served from `/sounds/...`.

## Expected files

- `new-message.mp3` — subtle ping played on new-message arrival (email + chat).
  See the Phase 2 sound design in `plans/mail/new-message-indicators-plan.md`.
- `new-notification.mp3` — ping for the notification bell (`@`-mentions,
  approvals, etc.); separate subsystem from new-message arrival.
